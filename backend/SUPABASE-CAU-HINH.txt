YUMEGO-JI — Kết nối Supabase (PostgreSQL)
=========================================

1) Lấy mật khẩu DB
   Supabase Dashboard → Project Settings → Database → Database password
   (Nếu quên: Reset database password, rồi cập nhật lại trên Railway.)

2) Connection string khuyến nghị (Session pooler, IPv4)
   Host: aws-1-ap-southeast-2.pooler.supabase.com
   Username: postgres.jvdghkjkgrdogpymnwpu   ← bắt buộc dạng postgres.<project-ref> trên pooler
   Database: postgres
   Port: 5432

   Key=value (dán vào Railway — ƯU TIÊN, tránh lỗi cắt password URI):

   Host=aws-1-ap-southeast-2.pooler.supabase.com;Port=5432;Database=postgres;Username=postgres.jvdghkjkgrdogpymnwpu;Password=MAT_KHAU_THAT;SSL Mode=Require

3) Railway Variables (bắt buộc để login production)
   a) Xóa / sửa biến DATABASE_URL nếu mật khẩu sai (log 28P01 + PasswordLen sai).
   b) Thêm biến:

      Name:  ConnectionStrings__DefaultConnection
      Value: (chuỗi Host=... ở bước 2, Password = mật khẩu Database thật)

   Hoặc tách biến (BE ghép tự động):
      SUPABASE_DB_HOST=aws-1-ap-southeast-2.pooler.supabase.com
      SUPABASE_DB_USER=postgres.jvdghkjkgrdogpymnwpu
      SUPABASE_DB_PASSWORD=<mật khẩu Database>
      SUPABASE_DB_NAME=postgres
      SUPABASE_DB_PORT=5432

   c) Redeploy service backend.

4) Local (không commit mật khẩu)
   Copy appsettings.Secrets.example.json → appsettings.Secrets.json
   Thay YOUR_SUPABASE_DB_PASSWORD bằng mật khẩu thật.

5) Log khởi động lành mạnh
   DB config: Host=aws-1-...; Username=postgres.jvdghkjkgrdogpymnwpu; PasswordLen=N; UsingPlaceholderPassword=False
   Đã kết nối PostgreSQL (Supabase) thành công.

   Nếu thấy 28P01 password authentication failed:
   → Password trên Railway ≠ mật khẩu Database trên Supabase. Sửa ConnectionStrings__DefaultConnection rồi Redeploy.
   → PasswordLen=11 thường là mật khẩu cũ/cắt cụt — đừng dùng URI nếu password có @ # % ; dùng key=value.

6) Không ghi mật khẩu vào appsettings.json (file commit).
